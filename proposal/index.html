SCOPE

変えるところ / 変えないところ

触っているのは基本的に見た目だけです。どこに何が書いてあるかは今と同じなので、迷子になりません。

KEEP変えないもの

  • セクションの順番（ミッション → 活動内容 → 挨拶 → 役員 → 実績 → ブログ → お問い合わせ）
  • ページ構成とURL（トップ / ブログの2枚構成）
  • 掲載している文章・実績・役員プロフィールの中身（全文そのまま）
  • ブログ記事4件（note リンク・画像・本文すべて）
  • ページ内リンクのアンカー名（#mission など）
  • 編集モードの操作方法と、役員写真の保存先

CHANGE変えるもの

  • 配色：オレンジ系 → 黒・白・コーラル（ブランドガイド準拠）
  • 見出し書体：Archivo Black を採用
  • トップに墨絵の海岸線キービジュアルを配置
  • キャッチコピーを FROM YOKOSUKA TO THE NEXT GENERATION. に（日本語も併記）
  • 「CONNECT / LEARN / CHALLENGE / GROW」の4本柱を新設
  • 活動内容：カード6枚 → 番号付きの一覧
  • ブログ：記事一覧を大きな写真つきに
  • メニューを英語＋日本語の2段表示に（かっこよさと分かりやすさの両立）
  • 装飾（パーティクル・グロー）を削除

CHANGES

主な変更点

意見をもらうときは、この番号（D-01 など）を書いてもらうと話が早いです。

D-01
キービジュアルの導入
トップに墨絵タッチの海岸線（灯台・街並み・水面）を配置。現時点ではコードで描いた図形なので、正式なイラスト画像が用意できれば差し替えられます（R-02）。
D-02
キャッチコピーの英語化（日本語も併記）
FROM YOKOSUKA TO THE NEXT GENERATION. を大きく出しつつ、すぐ下に「esportsで、横須賀の次世代を育てる。」を残しました。学校や行政の方が最初に見ても意味が伝わります。
D-03
メニューを英語＋日本語の2段に
英語だけだと格好はつくものの分かりにくいので、小さく日本語を添えました。「かっこよさ」と「迷わなさ」を両立させるための調整です。
D-04
4本柱セクションの新設
CONNECT / LEARN / CHALLENGE / GROW を横一列で表示。「結局この団体は何をしているのか」を最初の数秒で伝える枠です。
D-05
ミッションを黒背景に
一番読ませたい文章のところで背景を反転。スクロール中に「ここは大事」と体感で分かります。
D-06
活動内容をリスト型へ
カード6枚だと文章量の差でバラバラに見えるため、番号＋見出し＋説明の横並びに変更。上から順に読めます。
D-07
活動記録 → ブログ に改名
メニュー・ページタイトル・見出しを「ブログ」に統一しました（今のサイトにも反映済み）。
D-08
新歓レポートを活動実績へ移動
「新入生歓迎会2026」はブログ記事ではなく活動実績に移しました。note へのリンクは実績の中に残してあります（今のサイトにも反映済み）。
D-09
ブログ記事一覧を写真つきに
サムネイルを大きく取り、モノクロ→ホバーでカラーに。掲載中の4記事・noteリンク・画像はそのままです。
D-10
装飾エフェクトの削除
背景に浮いていた粒子や発光をなくしました。スマホでの動作が軽くなり、文字も読みやすくなります。

DECISIONS

みんなに決めてほしいこと

全部に答える必要はありません。気になったものだけ番号を指定して答えてもらえれば十分です。

R-01この見た目で差し替えていい？

黒 × 白 × コーラルの硬派な雰囲気になります。今より「団体としての本気度」は上がりますが、「高校生向けの親しみやすさ」は少し下がるかもしれません。

この内容で差し替える方向性は良いが要調整今のままがいい
R-02キービジュアルの画像素材はある？

いまはコードで描いた簡易版です。ブランドガイドの元イラスト（PNG / SVG）があれば差し替えて完成度が上がります。

素材を渡せる作れる人がいる今の簡易版で進める
R-03プレイヤーマップはどうする？

今はメニューから外れたままです。差し替えに合わせて作り直して復活させるか、このまま非掲載にするか。

作り直して復活当面は非掲載完全に廃止
R-04役員の顔写真を入れる？

いまは頭文字のアイコンです。モノクロ写真にすると一気に本格的になりますが、全員分の写真が必要になります（アップロード機能は動きます）。

モノクロ写真で統一頭文字のままでOK希望者だけ写真
R-05差し替えるタイミングは？

反映作業自体はすぐ終わります。イベント直前を避けたい等の希望があれば合わせます。

決まり次第すぐ日程を相談したいもう少し様子を見たい

HOW TO APPLY

OKが出たら、こう差し替わります

差し替え版は本番と別の場所（proposal/site/）に置いてあるので、今のサイトには影響していません。 2つのファイルは単体で完成しているのでそのまま置き換えるだけです。URLは変わりません。

ページ差し替え版本番公開URL
トップproposal/site/index.html→index.html変わらない
ブログproposal/site/news.html→news.html変わらない

画面左下の「← 比較ページへ戻る」ボタンは確認用なので、差し替えるときに消えます（保存機能を使った場合も自動で除かれます）。 差し替え前に必ずもう一度共有しますし、元に戻せるよう履歴も残します。

OPEN ITEMS

正直に共有しておくこと

キービジュアルは簡易再現版ブランドガイドの海岸線をコードで描き起こしたものです。正式なイラスト素材が届き次第、差し替えれば完成度が上がります（R-02）。
今のブログの保存機能は壊れています編集モードで記事を足しても、ダウンロードされるファイルには反映されません。以前ブログ記事が消えたように見えたのは、これが原因の可能性が高いです。差し替え版では直っていますが、差し替えるまでは記事の追加を私に依頼してください。
SNSシェア用の画像（OGP画像）は未設定SNSに貼ったときのサムネイル画像がまだありません。ブランドガイドのキービジュアルから作る想定です。
役員写真は各自の端末に保存される仕組み今のサイトと同じ仕様で、アップロードした写真はその端末にしか残りません。全員に見せるには保存機能でファイル化する必要があります。改善は別途相談させてください。
