SITE RENEWAL PROPOSAL — 案A

ブランドガイドに合わせた
サイトデザイン刷新の提案

新しいキービジュアル（墨絵の横須賀海岸線 × Archivo Black × コーラル）に合わせて、サイトの見た目を作り直す提案です。 情報の並び順・ページ構成・掲載内容は一切変えていません。変わるのは「見え方」だけなので、 いま使っている案内やリンクがそのまま使えます。

SCOPE

変えるところ / 変えないところ

「デザインを大きく変える」と聞くと迷子になりそうで不安になりますが、今回は触る場所を見た目だけに限定しています。 どこに何が書いてあるかは今と同じです。

KEEP変えないもの

  • セクションの順番（ミッション → 活動内容 → 挨拶 → 役員 → 実績 → 活動記録 → お問い合わせ）
  • ページ構成とURL（トップ / 活動記録 は今のまま）
  • 掲載している文章・実績・役員プロフィールの中身
  • ページ内リンクのアンカー名（#mission など）＝共有済みリンクが切れません
  • 役員カードをクリックすると詳細が開く操作
  • 編集モードなど、運用側の仕組み

CHANGE変えるもの

  • 配色：青系 → 黒・白・コーラル（ブランドガイド準拠）
  • 見出し書体：Archivo Black を採用し英字を主役に
  • トップに墨絵の海岸線キービジュアルを配置
  • キャッチコピーを FROM YOKOSUKA TO THE NEXT GENERATION. に
  • 「CONNECT / LEARN / CHALLENGE / GROW」の4本柱を新設
  • 活動内容：カード6枚 → 番号付きの一覧（読みやすさ優先）
  • 装飾（パーティクル・グロー）を削除しシンプルに

CHANGES

主な変更点

意見をもらうときは、この番号（D-01 など）を書いてもらうと話が早いです。

D-01
キービジュアルの導入
トップに墨絵タッチの海岸線（灯台・街並み・水面）を配置。ブランドガイドのビジュアルをWebで再現しています。現時点ではコードで描いた図形なので、正式なイラスト画像が用意できれば差し替えられます。
D-02
キャッチコピーの英語化
「esportsで、横須賀の次世代を育てる。」を FROM YOKOSUKA TO THE NEXT GENERATION. に。日本語の説明文はすぐ下に残してあるので、意味が伝わらない心配はありません。
D-03
4本柱セクションの新設
CONNECT / LEARN / CHALLENGE / GROW を横一列で表示。「結局この団体は何をしているのか」を3秒で伝える枠です。
D-04
ミッションを黒背景に
一番読ませたい文章のところで背景を黒に反転。スクロール中に「ここは大事」と体感で分かるようにしています。
D-05
活動内容をリスト型へ
カード6枚だと文章量の差でバラバラに見えるため、番号 + 見出し + 説明の横並びに変更。上から順に読めるので長い説明でも崩れません。
D-06
装飾エフェクトの削除
背景に浮いていた粒子や発光をなくしました。スマホでの動作が軽くなり、文字も読みやすくなります。
D-07
JOIN US ボタンの常設
ヘッダーの右端に常に置きます。どこを読んでいても連絡先に飛べる状態を作ります（リンク先は現行と同じお問い合わせ欄）。
D-08
プレイヤーマップは非掲載のまま
現行と同じく、メニューには入れていません。復活させるかどうかは別途相談したい項目です（R-04）。

DECISIONS

みんなに決めてほしいこと

全部に答える必要はありません。気になったものだけ番号を指定して答えてもらえれば十分です。

R-01この方向性で進めていい？

黒 × 白 × コーラルの硬派な雰囲気になります。今より「団体っぽさ・本気度」は上がりますが、「高校生向けの親しみやすさ」は少し下がる可能性があります。

このまま進める方向性は良いが要調整現行のままがいい
R-02英語のキャッチコピーで大丈夫？

学校や行政の方が最初に見る画面が英語になります。日本語を主役に戻す案も作れます。

英語のままでOK日本語を主役にしたい英語+日本語を同じ大きさで
R-03キービジュアルの画像素材はある？

いまはコードで描いた簡易版です。ブランドガイドの元イラスト（PNG/SVG）があれば、そのまま差し替えて完成度が上がります。

素材を渡せる作れる人がいる今の簡易版で進める
R-04プレイヤーマップはどうする？

現在メニューから外しています。デザイン刷新に合わせて作り直して復活させるか、このまま非掲載にするか。

作り直して復活当面は非掲載完全に廃止
R-05役員の顔写真を入れる？

いまは頭文字のアイコンです。モノクロ写真にすると一気に本格的になりますが、全員分の写真が必要になります。

モノクロ写真で統一頭文字のままでOK希望者だけ写真

意見の出し方.

Discord に貼り付けるだけで済むテンプレートを用意しました。 全部埋める必要はありません。気になった番号だけ書いてもらえれば大丈夫です。

STEP 1「案Aを全画面で見る」でひと通りスクロールする（PCとスマホ両方あると助かります）
STEP 2気になった箇所の番号（D-01 / R-03 など）をメモする
STEP 3下のテンプレートをコピーして Discord に投稿する
